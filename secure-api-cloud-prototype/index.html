Planned request path

1
Browser or appCalls a public HTTPS API hostname and authenticates.
2
GatewayChecks identity, route allowlist, request size, method, rate limits and security policy.
3
Authenticated tunnelForwards permitted traffic to a registered origin without exposing its inbound port.
4
Origin serverProcesses the request and returns a response over the protected connection.

Release security checklist

  • Use maintained TLS and cryptographic libraries; do not invent a custom encryption algorithm.
  • Keep origin tunnel credentials and API secrets in server-side secret storage.
  • Scan dependencies weekly and when code changes; triage critical alerts immediately.
  • Test fixes in CI and staging, verify release artifacts, deploy gradually, and keep rollback ready.
  • Never automatically install unreviewed code on customer-owned servers.
